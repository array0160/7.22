v7.0 NEW PRIMARY PATH

標準 PP-OCRv6：Detector 四邊形 → 直接 Recognition

這條路徑仍完全不使用 PCA 中心線或 V3 corridor。 第一遍用 v5 Detector 正常找框，第二遍用同一 Detector 的 1.2× 敏感模式「只補第一遍完全沒抓到的框」。 Recognition 時，短欄整條送 v6；長欄依 Detector 四邊形沿長軸切成約 10～12 字小段再辨識。

✓ v5 Detector：老書直欄較穩 ✓ 第二遍只補漏框，不覆蓋第一遍 ✓ v6 Recognition：短繁體字較強 ✓ 長欄自動切成 10～12 字小段 ✓ 可疑小段才擴框重認一次 ✓ 不用中心線 / V3 corridor
第二遍 Detector 只新增第一遍沒有的框；不會拿較寬的第二遍框去取代原框，所以不會再把其他欄裁壞。 Recognition 前先看原始像素是否真的有深色前景、局部對比與垂直筆畫覆蓋。 沒有足夠墨跡的框直接丟掉，不讓 recognizer 在空白上硬猜中文字。
